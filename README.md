## Description
This repository contains the R code related to the publication by [Jalkanen & Zhong et al. (2025)](https://www.sciencedirect.com/science/article/pii/S155041312500539X).

In this project, we comprehensively profiled abdominal subcutaneous and four visceral depots from eight men and women using single-nucleus RNA sequencing (snSeq) and spatial transcriptomics (STx). Through integrative analyses using existing and in-house developed tools, we uncovered unexpected structural organization of all five depots and identified region-specific cellular features, including distinct cell-cell communication routes. Mechanistically, we observed intricate interactions between adipocytes and myeloid cells, which were particularly pronounced in epiploic WAT. These findings highlight the complex cellular architecture and functional diversity within different adipose depots.

Publication: Jalkanen & Zhong et al., "Cytoarchitectural multi-depot profiling reveals immune-metabolic crosstalk in human colon-associated adipose tissue", ***Cell Metabolism***, 13 Jan 2026 (online), DOI:10.1016/j.cmet.2025.12.008
